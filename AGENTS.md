# DEVITO Agent Instructions

This file is the repository-wide baseline for coding agents.

Follow `.github/copilot-instructions.md` as the detailed project policy. In particular:
- Make small, reversible, reviewable changes.
- Preserve existing behavior and repository conventions.
- Keep AVA tooling defensive/local and avoid unauthorized or destructive capabilities.
- Preserve evidence and integrity according to `docs/AVA_FLASH_IMMUTABLE_RULE.md`.
- Never claim tests or checks that were not actually run.
- Inspect before editing; validate after editing; report exact results.
- Do not weaken security controls or bypass authorization to make a test pass.
